# DSH 论文阅读器

在 DSH 对话旁阅读 PDF，随时解释文字、翻译段落、讨论图表，并将阅读讨论整理成笔记。

作者与贡献者：Jingyi HUANG、[flynnmav](https://github.com/flynnmav)。

## 安装

1. 在 DSH 插件管理器中选择「从 GitHub 安装」，输入 `Pierre1231/dsh-paper-reader`。
2. 启用 `dsh-paper-reader`；如提示重启，按提示操作。

仓库已包含构建产物，直接安装即可使用。

## 使用

打开工作区 PDF，在右侧预览器中选择「论文阅读」；也可通过会话顶部的「打开本地论文」选择本机 PDF。

- **文字讨论**：划词或悬停段落，使用解释、翻译、提问和复制。解释与翻译直接发送到当前会话，提问先写入草稿。
- **图表与公式**：解释图表或含公式的选段时，可附上高清截图，便于 AI 理解。
- **阅读工具**：适合宽度、缩放、全文搜索、目录、引用跳转和阅读位置记忆。
- **阅读笔记**：点击「笔记」，检查并发送草稿中的指令。AI 会按论文章节整理讨论，保留疑问、解答、推导和适用边界，并在工具可用时配上原文图表。

笔记保存到 `工作区根目录/{论文标题}/论文笔记.md`，配图放在同目录的 `figures/` 中。

## 注意事项

- 扫描版 PDF 暂不支持 OCR；复杂排版和特殊图注可能需要手动选择。
- 本地选择的 PDF 刷新后需要重新打开；可手动选择 Zotero 中的 PDF，但不自动同步 Zotero 数据库。
- 图表解释需要模型支持图片输入。笔记配图需要 AI 环境中有可用的 PDF 裁图工具。
- 遇到卡顿，可在阅读器内按 **Ctrl+Alt+D**（macOS 为 **⌘+⌥+D**）复制诊断报告。

## 本地开发

```sh
npm install
npm test
npm run build
```

在 DSH 插件管理器中添加本地项目目录并启用即可。版本变更见 [更新日志](CHANGELOG.md)。

动效与视觉交互回归：先运行 `npm run build`，再运行 `npm run test:motion`。测试会生成临时双页 PDF，在隔离的本地服务中检查菜单开合、悬停、操作反馈、加载、缩放、交叉主题、窄屏、搜索及引用跳转，不调用真实模型。macOS 默认使用已安装的 Microsoft Edge；其他浏览器通过 `CHROME_PATH` 指定 Chromium 可执行文件。主题截图保存在 `test-results/motion/`。

视觉优化按功能独立提交，且每次提交包含 `lib/client.js` 构建产物。需要撤销某项时使用 `git revert <提交号>`；若后续功能依赖它，按提交的逆序逐项回退。重新加载插件或重启 DSH 后生效。
